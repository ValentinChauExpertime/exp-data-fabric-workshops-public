## Explorer les données dans un DataFrame

Vous pouvez maintenant créer un **notebook Fabric** pour travailler avec vos données.  
Les notebooks offrent un environnement interactif dans lequel vous pouvez écrire et exécuter du code.

1. Dans la barre de menu à gauche, sélectionnez **Créer** (*Create*).Dans la page **Nouveau** (*New*), sous la section **Ingénierie des données** (*Data Engineering*), sélectionnez **Notebook**.
Un nouveau notebook nommé **Notebook 1** est alors créé et ouvert automatiquement.
