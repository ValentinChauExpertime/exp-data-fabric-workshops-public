## Explorer les données dans un DataFrame

Vous pouvez maintenant créer un **notebook Fabric** pour travailler avec vos données.  
Les notebooks offrent un environnement interactif dans lequel vous pouvez écrire et exécuter du code.

1. Dans la barre de menu à gauche, sélectionnez **Créer** (*Create*).Dans la page **Nouveau** (*New*), sous la section **Ingénierie des données** (*Data Engineering*), sélectionnez **Notebook**.
Un nouveau notebook nommé **Notebook 1** est alors créé et ouvert automatiquement.

![](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Apache%20Spark/new-notebook.png)

2. Fabric attribue un nom à chaque notebook que vous créez, par exemple Notebook 1, Notebook 2, etc.  
   Cliquez sur le panneau de nom situé au-dessus de l’onglet Accueil (Home) dans le menu pour changer ce nom en quelque chose de plus descriptif.

3. Sélectionnez la première cellule (qui est actuellement une cellule de code), puis dans la barre d’outils en haut à droite, utilisez le bouton **M↓** pour la convertir en cellule Markdown.  
   Le texte contenu dans la cellule sera alors affiché comme un texte formaté.
