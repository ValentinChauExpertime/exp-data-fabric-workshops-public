# Exercice : Introduction aux tables Delta dans Microsoft Fabric

## Introduction

Au sein de **Microsoft Fabric**, le **Lakehouse** constitue une solution moderne pour unifier le stockage de données brutes (comme dans un data lake) avec les fonctionnalités relationnelles d’un entrepôt de données. Les tables créées dans un Lakehouse s’appuient sur le format **open source Delta Lake**, qui apporte des fonctionnalités puissantes pour la gestion des données, notamment :

- Le support des **transactions ACID**,
- La gestion de l’**historique des versions** (time travel),
- L’**interopérabilité entre les traitements par lots et en continu**,
- Et la compatibilité avec les requêtes **SQL analytiques**.

Cet exercice pratique vous guidera à travers les étapes essentielles de création et d’exploitation de tables Delta dans Microsoft Fabric. Vous apprendrez non seulement à manipuler des données avec **Python (via DataFrames)** et **SQL**, mais aussi à comprendre comment Delta Lake facilite le traitement fiable et performant des données, y compris dans des scénarios de **streaming**.

> ⏱️ **Durée estimée** : environ 45 minutes  
> ⚠️ **Prérequis** : Un **accès à un locataire Microsoft Fabric** est requis pour effectuer cet exercice.

---

## Objectifs pédagogiques

À l’issue de cet exercice, vous serez capable de :

1. **Créer un espace de travail (workspace)** dans Microsoft Fabric pour organiser vos ressources.
2. **Créer un Lakehouse** et **téléverser des fichiers de données** à utiliser dans vos analyses.
3. **Explorer les données avec un DataFrame**, en utilisant un notebook intégré.
4. **Créer des tables Delta**, optimisées pour les traitements fiables et performants.
5. **Utiliser SQL pour créer une table Delta**, démontrant l’intégration native de ce format.
6. **Explorer la gestion des versions des tables** à l’aide des fonctionnalités de time travel.
7. **Analyser les données** contenues dans une table Delta à l’aide de requêtes SQL.
8. **Utiliser les tables Delta pour le streaming**, en exploitant les données en temps réel.
9. **Nettoyer les ressources** utilisées pour éviter toute consommation inutile.
