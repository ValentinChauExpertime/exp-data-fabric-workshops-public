## Création d’un espace de travail dans Microsoft Fabric

Avant de commencer à travailler avec les données dans Microsoft Fabric, il est essentiel de **créer un espace de travail (workspace)** au sein d’un locataire disposant d’une capacité Fabric activée. Cet espace de travail servira d’environnement de travail centralisé pour gérer vos projets, données et ressources.

### Étapes pour créer un workspace

1. **Accédez à la page d’accueil de Microsoft Fabric**  
   Ouvrez votre navigateur web et rendez-vous sur la page suivante :  
   [https://app.fabric.microsoft.com/home?experience=fabric-developer](https://app.fabric.microsoft.com/home?experience=fabric-developer)  
   Connectez-vous ensuite avec vos **identifiants Microsoft Fabric**.

2. **Ouvrez le menu des espaces de travail**  
   Dans la barre latérale située à gauche, cliquez sur **Workspaces**.  
   L’icône correspondante ressemble à ceci : 🗇.

3. **Créez un nouvel espace de travail**  
   - Cliquez sur le bouton **Créer un workspace** ou **New workspace**.  
   - Donnez un **nom significatif** à votre espace de travail pour pouvoir l’identifier facilement.  
   - Dans la section **Avancée** ou **Advanced**, choisissez un **mode de licence** qui inclut la capacité Fabric, par exemple :  
     - **Trial** (version d’essai),  
     - **Premium**,  
     - ou **Fabric** (selon votre abonnement).

4. **Validation et ouverture du workspace**  
   Une fois créé, votre nouvel espace de travail s’ouvrira automatiquement.  
   Il devrait apparaître **vide**, prêt à accueillir vos premiers projets, fichiers et tables.
   

![](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Apache%20Spark/new-workspace.png)

-> Vous êtes maintenant prêt à commencer la création de votre Lakehouse et à importer des données pour les analyser.

## Créer un Lakehouse et importer des fichiers

Maintenant que vous avez un espace de travail, il est temps de créer un **Lakehouse** pour y stocker vos données.

Dans la barre de navigation à gauche, sélectionnez **Créer** (*Create*).  
Dans la page **Nouveau** (*New*), sous la section **Ingénierie des données** (*Data Engineering*), sélectionnez **Lakehouse**.  
Donnez-lui un **nom unique** de votre choix.

> 💡 **Remarque** : Si l’option *Créer* n’est pas épinglée dans la barre latérale, vous devez d’abord cliquer sur l’icône **…** (points de suspension).

Après environ une minute, un **nouveau Lakehouse sera créé** :

![](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Apache%20Spark/new-lakehouse.png)

## Afficher le nouveau Lakehouse et importer un fichier

Une fois le Lakehouse créé, il s’ouvre automatiquement. Dans le **volet Explorateur** (Explorer) situé à gauche, vous pouvez parcourir les **tables** et les **fichiers** contenus dans le Lakehouse.

Vous allez maintenant **ingérer des données dans le Lakehouse**.  
Il existe plusieurs façons d’ajouter des données, mais dans cet exercice, vous allez simplement **télécharger un fichier texte** sur votre ordinateur local (ou machine virtuelle du laboratoire) et l’importer dans votre Lakehouse.

### Étapes à suivre :

1. **Téléchargez le fichier de données**  
   Cliquez sur le lien ci-dessous pour télécharger le fichier, puis enregistrez-le sous le nom `products.csv` :  
   👉 [https://github.com/MicrosoftLearning/dp-data/raw/main/products.csv](https://github.com/MicrosoftLearning/dp-data/raw/main/products.csv)

2. **Revenez à l’onglet du navigateur contenant votre Lakehouse**  
   Dans le **volet Explorateur**, à droite du dossier **Files**, cliquez sur le menu **…** (trois points), puis sélectionnez **New Folder**.

3. **Créez un sous-dossier nommé `products`**  
   Cela permettra de mieux organiser les fichiers importés.

4. **Importez le fichier `products.csv`**  
   Dans le menu **…** du dossier `products`, choisissez **Upload**, puis sélectionnez le fichier `products.csv` depuis votre ordinateur (ou votre machine virtuelle de laboratoire).

5. **Vérifiez que le fichier a bien été importé**  
   Cliquez sur le dossier `products` dans l’explorateur pour voir le fichier `products.csv` affiché.
