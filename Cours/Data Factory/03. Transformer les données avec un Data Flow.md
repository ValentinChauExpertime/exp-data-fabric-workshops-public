# Module 2 : Transformation des données avec un Data Flow dans Data Factory 


**Durée :** 25 minutes 


Avec les données brutes chargées dans votre table Bronze Lakehouse du dernier module, vous pouvez maintenant préparer ces données et les enrichir en les combinant avec une autre table qui contient des remises pour chaque fournisseur et leurs voyages au cours d’une journée donnée. Cette dernière table Gold Lakehouse est chargée et prête à être consommée.

Les étapes générales du Data Flow sont les suivantes :


1- Obtention des données brutes à partir de la table Lakehouse créée par l’activité Copy dans Module 1 : Créer un pipeline avec Data Factory.

2- Transformation des données importées à partir de la table Lakehouse.

3- Connexion à un fichier CSV contenant des données de remises.

4- Transformation des données des remises.

5- Combinaison des données de voyages et de remises.

6- Chargement de la table Gold Lakehouse


Importer des données à partir d’un Lakehouse
--------------------------------------------

1-  Dans la barre latérale, sélectionnez **Créer**, puis **Dataflow Gen2** pour créer un Data Flow gen2. [![Screenshot showing the Fabric Create page with the Dataflow Gen2 button highlighted.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/create-new-dataflow-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/create-new-dataflow.png#lightbox)
    
2-  Dans le menu nouveau Data Flow, sélectionnez **Obtenir des données**, puis **Plus...**.
    
    ![Screenshot showing the Dataflow menu with Get data button highlighted and the More... option highlighted from its menu.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/get-data-button.png)
    
3-  Recherchez et sélectionnez le connecteur **Lakehouse** .
    
    ![Screenshot showing the selection of the Lakehouse data source from the Choose data source menu.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/choose-lakehouse-data-source.png)
    
4-  La boîte de dialogue **Se connecter à la source de données** s’affiche et une nouvelle connexion est automatiquement créée pour vous en fonction de l’utilisateur actuellement connecté. Cliquez sur **Suivant**.
    
    [![Screenshot showing the configuration of the data source settings for your new Lakehouse with your current signed in user, and the Next button selected.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/lakehouse-settings-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/lakehouse-settings.png#lightbox)
    
5-  La boîte de dialogue **Sélectionner les données** s'affiche. Utilisez le volet de navigation pour rechercher le Lakehouse que vous avez créé pour la destination dans le module précédent, puis sélectionnez la table de données **Tutorial\_Lakehouse** .
    
    [![Screenshot showing the Lakehouse browser with the workspace, lakehouse, and table created with the Copy activity in module 1.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/browse-and-choose-tutorial-lakehouse-table-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/browse-and-choose-tutorial-lakehouse-table.png#lightbox)
    
6-  _(Facultatif)_ Une fois que votre canevas est rempli avec les données, vous pouvez définir des informations de **profil de colonne**, car cela est utile pour le profilage des données. Vous pouvez appliquer la transformation appropriée et cibler les valeurs de données appropriées en fonction de celle-ci.
    
    Pour ce faire, sélectionnez **Options** dans le volet du ruban, sélectionnez les trois premières options sous **Profil de colonne**, puis sélectionnez **OK**.
    
    ![Screenshot showing the column options selection for your data.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/column-profile-options.png)
    

Transformer les données importées à partir de Lakehouse
-------------------------------------------------------

1-  Sélectionnez l’icône de type de données dans l’en-tête de colonne de la deuxième colonne, **IpepPickupDatetime**, pour afficher un menu déroulant et sélectionnez le type de données dans le menu pour convertir la colonne du type **Date/Heure** en **Type Date** . ![Screenshot showing the selection of the Date data type for the IpepPickupDatetime column.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/select-date-type.png)
    
2-  _(Facultatif)_ Sous l’onglet **Accueil** du ruban, sélectionnez l’option **Choisir des colonnes** dans le groupe **Gérer les colonnes**.
    
    ![Screenshot showing the Choose columns button on the Home tab of the dataflow editor.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/choose-columns-button.png)
    
3-  _(Facultatif)_ Dans la boîte de dialogue **Choisir des colonnes**, désélectionnez certaines colonnes répertoriées ici, puis sélectionnez **OK**.
    
    *   lpepDropoffDatetime
    *   puLocationId
    *   doLocationId
    *   pickupLatitude
    *   dropoffLongitude
    *   rateCodeID
    
    ![Screenshot showing the Choose columns dialog with the identified columns deselected.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/choose-columns-dialog.png)
    
4-  Sélectionnez le filtre et le menu déroulant de tri de la colonne **storeAndFwdFlag** . (Si vous voyez une **liste d’avertissements peut être incomplète**, sélectionnez **Charger plus** pour afficher toutes les données.)
    
    ![Screenshot showing the filter and sort dialog for the column.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/filter-sort-values-dialog.png)
    
5-  Sélectionnez « Y » pour afficher uniquement les lignes où une remise a été appliquée, puis sélectionnez **OK**.
    
    ![Screenshot showing the values filter with only 'Y' selected.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/filter-values.png)
    
6-  Sélectionnez le menu déroulant tri et filtre de colonne **IpepPickupDatetime**, puis sélectionnez **Filtres de date**, puis choisissez le filtre **Entre…** fourni pour les types Date et Date/Heure.
    
    [![Screenshot showing the selection of the Date filters option in the column sort and format dropdown.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/date-filters-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/date-filters.png#lightbox)
    
7-  Dans la boîte de dialogue **Filtrer les lignes**, sélectionnez les dates comprises entre le 1er janvier 2015 et le 31 janvier 2015, puis sélectionnez **OK**.
    
    ![Screenshot showing the selection of the dates in January 2015.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/filter-dates-between.png)
    

Se connecter à un fichier CSV contenant des données de remise
-------------------------------------------------------------

Maintenant, avec les données des voyages en place, nous voulons charger les données qui contiennent les remises respectives pour chaque jour et VendorID, et préparer les données avant de les combiner avec les données de voyages.

1-  Sous l’onglet **Accueil** du menu de l’éditeur de Data Flow, sélectionnez l’option **Obtenir des données**, puis choisissez **Texte/CSV**.
    
    ![Screenshot showing the selection of the Get data menu from the Home tab, with Text/CSV highlighted.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/get-text-csv-data.png)
    
2-  Dans la boîte de dialogue **Se connecter à la source de données**, fournissez les détails suivants :
    
    *   **Chemin ou URL du fichier** - `https://raw.githubusercontent.com/ekote/azure-architect/master/Generated-NYC-Taxi-Green-Discounts.csv`
    *   **Type d’authentification** - Anonyme
    
    Sélectionnez ensuite **Suivant**.
    
    [![Screenshot showing the Text/CSV settings for the connection.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/text-csv-settings-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/text-csv-settings.png#lightbox)
    
3-  Dans la boîte de dialogue **Aperçu des données du fichier**, sélectionnez **Créer**.
    
    [![Screenshot showing the Preview file data dialog with the Create button highlighted.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/preview-file-data-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/preview-file-data.png#lightbox)
    

Transformer les données de remise
---------------------------------

1-  En examinant les données, nous voyons que les en-têtes semblent se trouver dans la première ligne. Promouvez-les en-têtes en sélectionnant le menu contextuel du tableau en haut à gauche de la zone de grille d’aperçu pour sélectionner **Utiliser la première ligne comme en-têtes**.
    
    ![Screenshot showing the selection of the Use first row as headers option from the table context menu.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/use-first-row-as-headers.png)
    
    Remarque
    
    Après avoir promu les en-têtes, vous pouvez voir une nouvelle étape ajoutée au volet **Étapes appliquées** en haut de l’éditeur de Data Flow pour les types de données de vos colonnes.
    
2-  Cliquez avec le bouton droit sur la colonne **VendorID** et, dans le menu contextuel affiché, sélectionnez l’option **Annuler le tableau croisé dynamique des autres colonnes**. Ceci vous permet de transformer des colonnes en paires attribut-valeur, où les colonnes deviennent des lignes.
    
    ![Screenshot showing the context menu for the VendorID column with the Unpivot other columns selection highlighted.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/unpivot-other-columns.png)
    
3-  Une fois la table non pivotée, renommez les colonnes **Attribut** et **Valeur** en double-cliquant dessus et en remplaçant **Attribut** par **Date** et **Valeur** par **Remise**.
    
    ![Screenshot showing the table columns after renaming Attribute to Date and Value to Discount.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/rename-unpivoted-columns.png)
    
4-  Modifiez le type de données de la colonne Date en sélectionnant le menu type de données à gauche du nom de la colonne et en choisissant **Date**.
    
    ![Screenshot showing the selection of the Date data type for the Date column.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/set-date-data-type.png)
    
5-  Sélectionnez la colonne **Remise**, puis sélectionnez l’onglet **Transformer** dans le menu. Sélectionnez **Colonne Nombre**, puis Transformations numériques **standard** dans le sous-menu, puis choisissez **Diviser**.
    
    [![Screenshot showing the selection of the Divide option to transform data in the Discount column.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/divide-column-values-inline.png)](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/divide-column-values.png#lightbox)
    
6-  Dans la boîte de dialogue **Diviser**, entrez la valeur 100.
    
    ![Screenshot showing the Divide dialog with the value 100 entered and the OK button highlighted.](https://learn.microsoft.com/fr-fr/fabric/data-factory/media/tutorial-end-to-end-dataflow/divide-dialog.png)
    

Combinez les données de voyages et de remises
---------------------------------------------

L’étape suivante consiste à combiner les deux tables en une seule table disposant de la remise qui doit être appliquée au trajet et du total ajusté.

1-  Tout d’abord, activez le bouton **Diagram View** pour voir vos deux requêtes.
    
![image](https://github.com/user-attachments/assets/fcb735de-79c2-4fe3-9c72-f70eb1c277ad)
    
2-  Sélectionnez la **requête nyc\_taxi**, puis, sous l’onglet **Accueil**, sélectionnez le menu **Combiner** et choisissez **Fusionner les requêtes**, puis **Fusionner les requêtes comme étant nouvelles**.
    
![image](https://github.com/user-attachments/assets/04c8f9d4-f894-42f3-a12f-7d836950515a)
    
3-  Dans la boîte de dialogue **Fusionner**, sélectionnez **Generated-NYC-Taxi-Green-Discounts** dans la **liste déroulante Droite pour la fusion** , puis sélectionnez l’icône « ampoule » en haut à droite de la boîte de dialogue pour voir le mappage suggéré des colonnes entre les deux tables.
    
![image](https://github.com/user-attachments/assets/87bc0a3d-f6fc-47e7-960f-f14812516101)
    
    Choisissez chacun des deux mappages de colonnes suggérés, un par un, en mappant les colonnes VendorID et date des deux tables. Lorsque les deux mappages sont ajoutés, les en-têtes de colonne correspondants sont mis en surbrillance dans chaque table.
    
4-  Un message s’affiche vous demandant d’autoriser la combinaison de données provenant de plusieurs sources de données pour afficher les résultats. Sélectionnez **OK** dans la boîte de dialogue **Fusionner**.
    
![image](https://github.com/user-attachments/assets/d95e727c-9ea3-4a36-8363-97351405ea87)
    
5-  Dans la zone de table, vous voyez d’abord un avertissement indiquant que « L’évaluation a été annulée, car la combinaison de données de plusieurs sources peut révéler des données d’une source à une autre. Sélectionnez Continuer si la possibilité de révéler des données est acceptable. » Sélectionnez **Continuer** pour afficher les données combinées.
    
![image](https://github.com/user-attachments/assets/a09e8b72-0581-417c-840b-8a090f93b696)
    
6-  Notez comment une nouvelle requête a été créée en mode Diagramme montrant la relation entre la nouvelle requête de fusion et les deux requêtes que vous avez créées précédemment. En regardant le volet table de l’éditeur, faites défiler vers la droite de la liste des colonnes de requête de fusion pour voir qu’une nouvelle colonne avec des valeurs de table est présente. Il s’agit de la colonne « Generated NYC Taxi-Green-Discounts » et son type est **\[Table\]**. Dans l’en-tête de colonne se trouve une icône avec deux flèches allant dans des directions opposées, ce qui vous permet de sélectionner des colonnes dans la table. Désélectionnez toutes les colonnes à l’exception de **Discount**, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/73481e45-0186-4f68-8897-ab2f995648f0)
    
7-  Avec la valeur de remise maintenant au niveau de la ligne, nous pouvons créer une nouvelle colonne pour calculer le montant total après la remise. Pour ce faire, sélectionnez l’onglet **Ajouter une colonne** en haut de l’éditeur, puis choisissez **Colonne personnalisée** dans le groupe **Général** .
    
    ![image](https://github.com/user-attachments/assets/254109e4-ea0b-4f81-ac24-d0e4e1b58a22)

    
8-  Dans la boîte de dialogue **Colonne personnalisée**, vous pouvez utiliser le [langage de formule Power Query (également appelé M)](https://learn.microsoft.com/fr-fr/powerquery-m) pour définir la façon dont votre nouvelle colonne doit être calculée. Entrez _TotalAfterDiscount_ pour le **nouveau nom de colonne**, sélectionnez **Devise** pour le **type de données** et fournissez l’expression M suivante pour la **formule de colonne personnalisée** :

    ```M
    si \[totalAmount\] > 0 alors \[totalAmount\] \* ( 1 -\[Discount\] ) autre \[totalAmount\]
    ```
    
    Sélectionnez ensuite **OK**.
    
![image](https://github.com/user-attachments/assets/4f9843ec-c224-45af-afc8-3a0d390caf36)

    
9-  Sélectionnez la colonne **TotalAfterDiscount** nouvellement créée, puis sélectionnez l’onglet **Transformer** en haut de la fenêtre de l’éditeur. Dans le groupe de **colonne Nombre**, sélectionnez la liste déroulante **Roundir,** puis choisissez **Round...**.
    
![image](https://github.com/user-attachments/assets/423cefdf-470a-4cec-92f3-bc03fe30a169)
    
10-  Dans la boîte de dialogue **Round**, entrez 2 pour le nombre de décimales, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/783abacf-2877-445c-885d-806cf8a20603)

    
11-  Modifiez le type de données de l’IpepPickupDatetime de Date à Date/Heure.
    
![image](https://github.com/user-attachments/assets/d32850b4-b501-450a-bafd-12cd7ab46f17)

    
12-  Enfin, développez le volet **Paramètres** de requête à droite de l’éditeur s’il n’est pas déjà développé, puis renommez la requête **fusion** en **sortie**.
    
![image](https://github.com/user-attachments/assets/1b017e44-f500-4cde-a7e2-a7c912ca3b2b)
    

Charger la requête de sortie dans une table dans lakehouse
----------------------------------------------------------

Une fois la requête de sortie entièrement préparée et les données prêtes à être sorties, nous pouvons définir la destination de sortie de la requête.

1-  Sélectionnez la requête de fusion de **sortie** créée précédemment. Sélectionnez ensuite l’onglet **Accueil** dans l’éditeur, puis **Ajouter une destination de données** dans le groupe de **requêtes** pour sélectionner une destination **Lakehouse** .
    
![image](https://github.com/user-attachments/assets/edd2e5f8-68f8-4bc3-8daf-b489ff1584fc)

    
2-  Dans la boîte de dialogue **Se connecter à la destination des données**, votre connexion doit déjà être sélectionnée. Sélectionnez **Suivant** pour continuer.
    
3-  Dans la boîte de dialogue **Choisir une cible de destination**, accédez au Lakehouse où vous souhaitez charger les données et nommer la nouvelle table _nyc\_taxi\_with\_discounts_, puis sélectionnez à nouveau **Suivant**.
    
![image](https://github.com/user-attachments/assets/e20aead9-e16b-4910-ac5a-6c2c1599952b)

    
4-  Dans la boîte de dialogue **Choisir les paramètres de destination**, conservez la méthode **Remplacer** la mise à jour par défaut, vérifiez que vos colonnes sont mappées correctement, puis sélectionnez **Enregistrer les paramètres**.
    
![image](https://github.com/user-attachments/assets/a9207d3d-b615-4573-b5c1-6fa73f2cb016)

    
5-  De retour dans la fenêtre de l’éditeur principal, vérifiez que vous voyez votre destination de sortie dans le volet **Paramètres de la requête** pour la table **Sortie**, puis sélectionnez **Publier**.
    
6-  _(Facultatif)_ Dans la page de l’espace de travail, vous pouvez renommer votre Data Flow en sélectionnant les points de suspension à droite du nom du Data Flow qui apparaît après avoir sélectionné la ligne, puis en choisissant **Propriétés**.

    ![image](https://github.com/user-attachments/assets/9aad2ad4-b128-4cf5-bc5a-41c988033a4c)

    
7-  Sélectionnez l’icône d’actualisation du Data Flow après avoir sélectionné sa ligne. Lorsque vous avez terminé, vous devez voir votre nouvelle table Lakehouse créée comme configurée dans les paramètres de **destination des données** .
    
![image](https://github.com/user-attachments/assets/70a5377c-f751-4b3b-be1d-e2a855b3a3cd)
    
8-   Vérifiez votre Lakehouse pour afficher la nouvelle table qui y est chargée.
