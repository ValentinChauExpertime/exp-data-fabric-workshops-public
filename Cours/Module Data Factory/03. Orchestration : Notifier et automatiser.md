# Module 3 : Automatiser et Envoyer des notifications avec Data Factory

**Durée :** 10 minutes

Dans ce module, vous allez découvrir comment :

1- Ajouter une activité Office 365 Outlook pour envoyer la sortie d’une activité de copie par e-mail.  
2- Ajouter une planification pour exécuter le pipeline.


Ajouter une activité Office 365 Outlook à votre pipeline
--------------------------------------------------------

Nous utilisons le pipeline que vous avez créé dans Module 1 : créer un pipeline dans Data Factory.

1-  Sélectionnez l’onglet **Activities** dans l’éditeur de pipeline et recherchez l’activité Office Outlook.

![image](https://github.com/user-attachments/assets/6e89bcd1-9d64-471b-8d4d-c9c0d1b1bdb3)

    
2-  Sélectionnez **OK** pour autoriser l’utilisation de votre adresse e-mail.
    
![image](https://github.com/user-attachments/assets/72897397-6c4e-4c82-b2ec-1391d5057c0a)
    
3-  Sélectionnez l’adresse e-mail que vous souhaitez utiliser.

![image](https://github.com/user-attachments/assets/acc60ed2-de7f-4162-9e46-af93a6b6458f)

    
> [!IMPORTANT]  
> Actuellement, le service ne prend pas en charge la messagerie personnelle. Vous devez utiliser un adresse e-mail de l’entreprise.

    
4- Sélectionnez **Allow access** pour confirmer.
    
![image](https://github.com/user-attachments/assets/0ea11c17-e95f-47c5-954e-a88b75fba2fd)
    
5-  Sélectionnez et faites glisser le chemin d’accès **réussite** (une case à cocher verte en haut à droite de l’activité dans le canevas de pipeline) de votre activité de copie vers votre nouvelle activité Office 365 Outlook.

![image](https://github.com/user-attachments/assets/9a42a67a-2dcf-4ee2-a74e-6f9b41115435)


6-  Sélectionnez l’activité Office 365 Outlook dans le canevas du pipeline, puis sélectionnez l’onglet **Settings** de la zone de propriété sous le canevas pour configurer l’e-mail.
    
Entrez votre adresse e-mail dans la section **To**. Si vous souhaitez utiliser plusieurs adresses, utilisez **;** pour les séparer.
Pour **Subject**, sélectionnez le champ afin que l’option **Add dynamic content** s’affiche, puis sélectionnez-le pour afficher le canevas du générateur d’expressions de pipeline.
    
![image](https://github.com/user-attachments/assets/a41af615-1b3b-437c-876e-19c12bed99e7)
    
7-  La boîte de dialogue **Pipeline expression builder** s’affiche. Entrez l’expression suivante, puis sélectionnez **OK** :
    
    _@concat('DI en une heure, pipeline réussi avec l’ID d’exécution Pipeline', pipeline(). RunId)_
    
![image](https://github.com/user-attachments/assets/8d071ed0-4309-46ff-ad79-ad2903c29355)


8-  Pour **corps,** sélectionnez à nouveau le champ et choisissez l’option **Add dynamic content** lorsqu’elle apparaît sous la zone de texte. Ajoutez à nouveau l’expression suivante dans la boîte de dialogue **Pipeline expression builder** qui s’affiche, puis sélectionnez **OK** :
    
    _@concat('RunID = ', pipeline(). RunId, ' ; ', 'Lignes copiées', activité('Copier les données1').output.rowsCopied, ' ; ','Débit ', activité('Copier les données1').output.throughput)_
    
> [!NOTE]      
> Remplacez **Copy data1** par le nom de votre propre activité de copie de pipeline.
    
9-  Enfin, sélectionnez l’onglet **Home** en haut de l’éditeur de pipeline, puis choisissez **Run**. Sélectionnez ensuite **Enregistrer et exécuter** à nouveau dans la boîte de dialogue de confirmation pour exécuter ces activités.

![image](https://github.com/user-attachments/assets/ac6e02bc-c50e-4c00-a329-5be3b9b98bb0)

    
10-  Une fois le pipeline exécuté correctement, vérifiez votre e-mail pour trouver l’e-mail de confirmation envoyé à partir du pipeline.

![image](https://github.com/user-attachments/assets/5941140b-b0d8-465c-8f58-f529dc5ae3b1)

    

Planifier l’exécution du pipeline
---------------------------------

Une fois que vous avez terminé le développement et le test de votre pipeline, vous pouvez le planifier pour qu’il s’exécute automatiquement.

1-   Sous l’onglet **Home** de la fenêtre de l’éditeur de pipeline, sélectionnez **Schedule**.
    
![image](https://github.com/user-attachments/assets/2ca86983-b77a-4d65-b6f8-99ee8c306dbc)

    
2- Configurez la planification en fonction des besoins. L’exemple ci-dessous planifie l’exécution quotidienne du pipeline à 20h00 jusqu’à la fin de l’année.
    
![image](https://github.com/user-attachments/assets/07a8b491-a994-4d4a-a118-d6a19c0c0fa1)
    

Ajouter une activité de data flow au pipeline
------------------------------------------------------------------

Vous pouvez également ajouter le flux de données que vous avez créé dans le Module 2 : créer un flux de données dans Data Factory dans le pipeline.

1-  Passez la souris sur la ligne verte reliant la copy activity et l’activité Office 365 Outlook sur votre canevas de pipeline, puis sélectionnez le bouton **+** pour insérer une nouvelle activité.

![image](https://github.com/user-attachments/assets/8108bfd3-1ae1-47e4-a1d7-1331db26815b)

    
2-  Choisissez **Data Flow** dans le menu qui s’affiche.

![image](https://github.com/user-attachments/assets/2de95102-661e-4b64-9c95-c5022cea987c)

    
3- L’activité Data flow nouvellement créée est insérée entre le activité de copie et l’activité Office 365 Outlook, puis sélectionnée automatiquement, affichant ses propriétés dans la zone sous le canevas. Sélectionnez l’onglet **Settings** dans la zone des propriétés, puis sélectionnez votre flux de données

![image](https://github.com/user-attachments/assets/27f81eaa-f118-4c55-bfc1-a64a69b55320)
