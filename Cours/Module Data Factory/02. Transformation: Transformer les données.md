# Module 2 : Transformation des données avec un Data Flow dans Data Factory 


**Durée :** 25 minutes 


Avec les données brutes chargées dans votre table Bronze Lakehouse du dernier module, nous allons maintenant préparer ces données et les enrichir en les combinant avec une autre table qui contient des remises pour chaque fournisseur et leurs voyages au cours d’une journée donnée

Les étapes générales du Data Flow sont les suivantes :


1- Obtention des données brutes à partir de la table Lakehouse créée par l’activité Copy dans Module 1 : Créer un pipeline avec Data Factory.

2- Transformation des données importées à partir de la table Lakehouse.

3- Connexion à un fichier CSV contenant des données de remises.

4- Transformation des données des remises.

5- Combinaison des données de voyages et de remises.

6- Chargement de la table Gold Lakehouse


Importer des données à partir d’un Lakehouse
--------------------------------------------

1-  Dans la barre latérale, sélectionnez **Create**, puis **Dataflow Gen2** pour créer un Data Flow gen2.

![image](https://github.com/user-attachments/assets/cdb5ee61-d67e-49d2-8958-eaf1d7f690e9)
    
2-  Dans le menu nouveau Data Flow, sélectionnez **Get Data**, puis **more...**.
    
![image](https://github.com/user-attachments/assets/9de21662-1858-4a0f-8730-8013e09ef349)

    
3-  Recherchez et sélectionnez le connecteur **Lakehouse** .
    
![image](https://github.com/user-attachments/assets/c020603d-a68b-428f-90cd-9fc4c97ba8c3)

    
4-  La boîte de dialogue **Connect to data source** s’affiche et une nouvelle connexion est automatiquement créée pour vous en fonction de l’utilisateur actuellement connecté. Cliquez sur **Next**.
  
![image](https://github.com/user-attachments/assets/fc372d7b-039f-4081-8d50-38970ea5202c)


    
5-  La boîte de dialogue **Choose data** s'affiche. Utilisez le volet de navigation pour rechercher le Lakehouse que vous avez créé pour la destination dans le module précédent, puis sélectionnez la table de données **Tutorial\_Lakehouse** .

    
![image](https://github.com/user-attachments/assets/fad36f57-79d8-4705-b4b6-c213f34a8a19)


    
6-  _(Facultatif)_ Une fois que votre canevas est rempli avec les données, vous pouvez définir des informations de **profil de colonne**, car cela est utile pour le profilage des données. Vous pouvez appliquer la transformation appropriée et cibler les valeurs de données appropriées en fonction de celle-ci.
    

Pour ce faire, sélectionnez **Options** dans le volet du ruban, sélectionnez les trois premières options sous **Column Profil**, puis sélectionnez **OK**.
    

![image](https://github.com/user-attachments/assets/7b072329-3162-401f-9c5e-717956ce2e74)

    

Transformer les données importées à partir du Lakehouse
-------------------------------------------------------

1-  Sélectionnez l’icône de type de données dans l’en-tête de colonne de la deuxième colonne, **IpepPickupDatetime**, pour afficher un menu déroulant et sélectionnez le type de données dans le menu pour convertir la colonne du type **Date/Heure** en **Type Date** 

![image](https://github.com/user-attachments/assets/9415be8e-85b3-4cbd-9ebf-bcd8924c1088)

    
2-  _(Facultatif)_ Sous l’onglet **Accueil** du ruban, sélectionnez l’option **Choisir des colonnes** dans le groupe **Gérer les colonnes**.
    
![image](https://github.com/user-attachments/assets/6e9aa48d-1b65-4440-a3b1-1269e21bad36)

    
3-  _(Facultatif)_ Dans la boîte de dialogue **Choose Columns**, désélectionnez certaines colonnes répertoriées ici, puis sélectionnez **OK**.
    
    *   lpepDropoffDatetime
    *   puLocationId
    *   doLocationId
    *   pickupLatitude
    *   dropoffLongitude
    *   rateCodeID
    

![image](https://github.com/user-attachments/assets/2f7d8155-5ab8-4d60-9fbc-d8b5cebde1f0)

    
4-  Sélectionnez le filtre et le menu déroulant de tri de la colonne **storeAndFwdFlag** . (Si vous voyez une **list may be incomplete**, sélectionnez **Load more** pour afficher toutes les données.)
    

![image](https://github.com/user-attachments/assets/ec3785dd-0059-4236-821d-b605af4e5a76)

    
5-  Sélectionnez « Y » pour afficher uniquement les lignes où une remise a été appliquée, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/0ded067b-a9ec-420f-a203-1ef31c7c2e84)

    
6-  Sélectionnez le menu déroulant tri et filtre de colonne **IpepPickupDatetime**, puis sélectionnez **Date Filter**, puis choisissez le filtre **Between…** fourni pour les types Date et Date/Heure.
    

![image](https://github.com/user-attachments/assets/ea807a99-1b38-4bcd-860a-36a3c8c0cb48)

    
7-  Dans la boîte de dialogue **Filter rows**, sélectionnez les dates comprises entre le 1er janvier 2015 et le 31 janvier 2015, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/a89676c0-a570-44bc-b00d-36426a2560e4)
    

Se connecter à un fichier CSV contenant des données de remise
-------------------------------------------------------------

Maintenant, avec les données des voyages en place, nous voulons charger les données qui contiennent les remises respectives pour chaque jour et VendorID, et préparer les données avant de les combiner avec les données de voyages.

1-  Sous l’onglet **Home** du menu de l’éditeur de Data Flow, sélectionnez l’option **Get data**, puis choisissez **Texte/CSV**.
    
![image](https://github.com/user-attachments/assets/3f58fb3e-a0a3-49a8-a798-0cc7732d11c6)

    
2-  Dans la boîte de dialogue **Connect to data source**, saisissez les détails suivants :
    
*   **Chemin ou URL du fichier** - `https://raw.githubusercontent.com/ekote/azure-architect/master/Generated-NYC-Taxi-Green-Discounts.csv`
*   **Type d’authentification** - Anonyme
    

Sélectionnez ensuite **Next**.
    
![image](https://github.com/user-attachments/assets/accbc18a-264a-43e9-b1b7-9b8569c25a26)

    
3-  Dans la boîte de dialogue **Aperçu des données du fichier**, sélectionnez **Créer**.
    

![image](https://github.com/user-attachments/assets/3aa48c3b-8f09-4102-8181-641c253f0e60)


Transformer les données de remise
---------------------------------

1-  En examinant les données, nous voyons que les en-têtes semblent se trouver dans la première ligne. Promouvez-les en-têtes en sélectionnant le menu contextuel du tableau en haut à gauche de la zone de grille d’aperçu pour sélectionner **Use first row as headers**.
    
![image](https://github.com/user-attachments/assets/0c6cdd52-fdd6-4758-8b13-ef606fe78dc4)

    
2-  Cliquez avec le bouton droit sur la colonne **VendorID** et, dans le menu contextuel affiché, sélectionnez l’option **Unpivot other columns**. Ceci vous permet de transformer des colonnes en paires attribut-valeur, où les colonnes deviennent des lignes.


![image](https://github.com/user-attachments/assets/6ca72905-4c86-439e-a604-f114bb385391)


    
3-  Une fois la table non pivotée, renommez les colonnes **Attribut** et **Valeur** en double-cliquant dessus et en remplaçant **Attribut** par **Date** et **Valeur** par **Remise**.
    
![image](https://github.com/user-attachments/assets/0d8c3ced-cbef-4947-a018-c4bb65395b61)

    
4-  Modifiez le type de données de la colonne Date en sélectionnant le menu type de données à gauche du nom de la colonne et en choisissant **Date**.
    
![image](https://github.com/user-attachments/assets/5b558c47-c793-44f3-a2c2-b9bd6290f2b7)

    
5-  Sélectionnez la colonne **Remise**, puis sélectionnez l’onglet **Transformer** dans le menu. Sélectionnez **Colonne Nombre**, puis Transformations numériques **standard** dans le sous-menu, puis choisissez **Diviser**.
    
![image](https://github.com/user-attachments/assets/a6cbf775-be28-4d62-b536-427bb82701fe)

    
6-  Dans la boîte de dialogue **Diviser**, entrez la valeur 100.
    
![image](https://github.com/user-attachments/assets/86d19d1f-7fb3-4a6a-b613-f221450d6ea8)

    

Combinez les données de voyages et de remises
---------------------------------------------

L’étape suivante consiste à combiner les deux tables en une seule table disposant de la remise qui doit être appliquée au trajet et du total ajusté.

1-  Tout d’abord, activez le bouton **Diagram View** pour voir vos deux requêtes.
    
![image](https://github.com/user-attachments/assets/fcb735de-79c2-4fe3-9c72-f70eb1c277ad)
    
2-  Sélectionnez la **requête nyc\_taxi**, puis, sous l’onglet **Accueil**, sélectionnez le menu **Combine** et choisissez **Merge queries**, puis **Merge queries as new**.
    
![image](https://github.com/user-attachments/assets/04c8f9d4-f894-42f3-a12f-7d836950515a)
    
3-  Dans la boîte de dialogue **Merge**, sélectionnez **Generated-NYC-Taxi-Green-Discounts** dans la **Rigth table for merge** , puis sélectionnez l’icône « ampoule » en haut à droite de la boîte de dialogue pour voir le mappage suggéré des colonnes entre les deux tables.
    
![image](https://github.com/user-attachments/assets/87bc0a3d-f6fc-47e7-960f-f14812516101)
    
    Choisissez chacun des deux mappages de colonnes suggérés, un par un, en mappant les colonnes VendorID et date des deux tables. Lorsque les deux mappages sont ajoutés, les en-têtes de colonne correspondants sont mis en surbrillance dans chaque table.
    
4-  Un message s’affiche vous demandant d’autoriser la combinaison de données provenant de plusieurs sources de données pour afficher les résultats. Sélectionnez **OK** dans la boîte de dialogue **Merge**.
    
![image](https://github.com/user-attachments/assets/d95e727c-9ea3-4a36-8363-97351405ea87)
    
5-  Dans la zone de table, vous voyez d’abord un avertissement indiquant que « L’évaluation a été annulée, car la combinaison de données de plusieurs sources peut révéler des données d’une source à une autre. Sélectionnez Continuer si la possibilité de révéler des données est acceptable. » Sélectionnez **Continue** pour afficher les données combinées.
    
![image](https://github.com/user-attachments/assets/a09e8b72-0581-417c-840b-8a090f93b696)
    
6-  Notez comment une nouvelle requête a été créée en mode Diagramme montrant la relation entre la nouvelle requête de fusion et les deux requêtes que vous avez créées précédemment. En regardant le volet table de l’éditeur, faites défiler vers la droite de la liste des colonnes de requête de fusion pour voir qu’une nouvelle colonne avec des valeurs de table est présente. Il s’agit de la colonne « Generated NYC Taxi-Green-Discounts » et son type est **\[Table\]**. Dans l’en-tête de colonne se trouve une icône avec deux flèches allant dans des directions opposées, ce qui vous permet de sélectionner des colonnes dans la table. Désélectionnez toutes les colonnes à l’exception de **Discount**, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/73481e45-0186-4f68-8897-ab2f995648f0)
    
7-  Avec la valeur de remise maintenant au niveau de la ligne, nous pouvons créer une nouvelle colonne pour calculer le montant total après la remise. Pour ce faire, sélectionnez l’onglet **Add column** en haut de l’éditeur, puis choisissez **Custom Column** dans le groupe **General** .
    

![image](https://github.com/user-attachments/assets/254109e4-ea0b-4f81-ac24-d0e4e1b58a22)

    
8-  Dans la boîte de dialogue **Custom Column**,  Entrez _TotalAfterDiscount_ pour le **New Column name**, sélectionnez **Devise** pour le **Data type** et entrez l’expression M suivante pour la **Custom Column formula** :

    
    
    if \[totalAmount\] > 0 then \[totalAmount\] \* ( 1 -\[Discount\] ) else \[totalAmount\]
    
    
Sélectionnez ensuite **OK**.
    
![image](https://github.com/user-attachments/assets/4f9843ec-c224-45af-afc8-3a0d390caf36)

    
9-  Sélectionnez la colonne **TotalAfterDiscount** nouvellement créée, puis sélectionnez l’onglet **Transform** au dessus de la fenêtre de l’éditeur. Dans le groupe de **colonne Nombre**, sélectionnez la liste déroulante **Roundir,** puis choisissez **Round...**.
    
![image](https://github.com/user-attachments/assets/423cefdf-470a-4cec-92f3-bc03fe30a169)
    
10-  Dans la boîte de dialogue **Round**, entrez 2 pour le nombre de décimales, puis sélectionnez **OK**.
    
![image](https://github.com/user-attachments/assets/783abacf-2877-445c-885d-806cf8a20603)

    
11-  Modifiez le type de données de l’IpepPickupDatetime de Date à Date/Heure.
    
![image](https://github.com/user-attachments/assets/d32850b4-b501-450a-bafd-12cd7ab46f17)

    
12-  Enfin, développez le volet **Query Settings** de requête à droite de l’éditeur s’il n’est pas déjà développé, puis renommez la requête **fusion** en **sortie**.
    
![image](https://github.com/user-attachments/assets/1b017e44-f500-4cde-a7e2-a7c912ca3b2b)
    

Charger la requête de sortie dans une table du lakehouse
----------------------------------------------------------

Une fois la requête de sortie entièrement préparée et les données prêtes à être sorties, nous pouvons définir la destination de sortie de la requête.

1-  Sélectionnez la requête de fusion de **sortie** créée précédemment. Sélectionnez ensuite l’onglet **Home** dans l’éditeur, puis **Add data destination** dans le groupe de **Query** pour sélectionner une destination **Lakehouse** .
    
![image](https://github.com/user-attachments/assets/edd2e5f8-68f8-4bc3-8daf-b489ff1584fc)

    
2-  Dans la boîte de dialogue **Se connecter à la destination des données**, votre connexion doit déjà être sélectionnée. Sélectionnez **Suivant** pour continuer.
    
3-  Dans la boîte de dialogue **Choose destination target**, accédez au Lakehouse où vous souhaitez charger les données et nommer la nouvelle table _nyc\_taxi\_with\_discounts_, puis sélectionnez à nouveau **Next**.
    
![image](https://github.com/user-attachments/assets/e20aead9-e16b-4910-ac5a-6c2c1599952b)

    
4-  Dans la boîte de dialogue **Choose destination settings**, conservez la méthode **Replace** la mise à jour par défaut, vérifiez que vos colonnes sont mappées correctement, puis sélectionnez **Save settings**.
    
![image](https://github.com/user-attachments/assets/a9207d3d-b615-4573-b5c1-6fa73f2cb016)

    
5-  De retour dans la fenêtre de l’éditeur principal, vérifiez que vous voyez votre destination de sortie dans le volet **Query settings** pour la table **Sortie**, puis sélectionnez **Publier**.
    
6-  _(Facultatif)_ Dans la page de l’espace de travail, vous pouvez renommer votre Data Flow en sélectionnant les points de suspension à droite du nom du Data Flow qui apparaît après avoir sélectionné la ligne, puis en choisissant **Properties**.

![image](https://github.com/user-attachments/assets/9aad2ad4-b128-4cf5-bc5a-41c988033a4c)

    
7-  Sélectionnez l’icône d’actualisation du Data Flow après avoir sélectionné sa ligne. Lorsque vous avez terminé, vous devez voir votre nouvelle table Lakehouse créée comme configurée dans les paramètres de **destination des données** .
    
![image](https://github.com/user-attachments/assets/70a5377c-f751-4b3b-be1d-e2a855b3a3cd)
    
8-   Vérifiez votre Lakehouse pour afficher la nouvelle table qui y est chargée.
