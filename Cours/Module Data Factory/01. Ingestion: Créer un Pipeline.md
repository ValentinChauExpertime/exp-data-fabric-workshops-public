# Créer un Data Pipeline

**Durée** : 10 minutes

1- Connectez-vous à http://app.fabric.microsoft.com/

2- Selectionnez l'expérience Data Factory 

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Create_Item1.png)



3- Sélectionnez Data Pipeline et saisissez un nom de pipeline. Cliquez ensuite Créer

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Create_Item2.png)


![image](https://github.com/user-attachments/assets/2a03ade6-7422-4096-ac6a-9b8ad3fcb7c9)


## Création d'une activité de Copie pour charger les données 

**Étape 1 :** Utilisez l’assistant de copie pour configurer une activité de copie.
Sélectionnez Copier les données pour ouvrir l’outil de assistant Copy.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline1.png)



**Étape 2 :** Configurez vos paramètres dans le assistant Copy.

1- La boîte de dialogue Copier les données s’affiche avec la première étape, Choisir une source de données, mise en surbrillance. 

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline2.png)


2- À l’étape suivante, sélectionnez Créer une connexion


![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline3.png)



3- Pour l’étape Choisir la destination des données de l’assistant Copy, sélectionnez Lakehouse, puis Suivant.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline4.png)

4- Sélectionnez Créer un lakehouse dans la page de configuration de destination des données qui s’affiche, puis entrez un nom pour le nouveau Lakehouse. Puis sélectionnez Suivant ensuite.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline5.png)

5- Configurez maintenant les détails de votre destination Lakehouse dans la page Sélectionner et mapper le chemin d’accès ou la table du dossier. Sélectionnez Tables pour le dossier Racine, 
mettez un nom de table, puis choisissez l’action overwrite. Ne cochez pas la case Activer la partition qui s’affiche après avoir sélectionné l’action Remplacer la table.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline5.png)


6- Enfin, dans la page Vérifier + enregistrer de l’assistant de copie des données, passez en revue la configuration. 
Pour ce tutoriel, décochez la case Démarrer le transfert de données immédiatement, car nous exécutons l’activité manuellement à l’étape suivante. Sélectionnez ensuite OK.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline6.png)

### Étape 3 : Exécutez et affichez les résultats de votre activité Copy.

1- Sélectionnez l’onglet Exécuter dans l’éditeur de pipeline. Sélectionnez ensuite le bouton Exécuter, puis Enregistrez et exécutez à l’invite pour exécuter l’activité Copy.

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline7.png)

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/01_Ingestion/Build_Data_Pipeline8.png)



2- Vous pouvez superviser l’exécution, puis vérifier les résultats sous l’onglet Sortie sous le canevas du pipeline.
Sélectionnez le bouton Détails de l’exécution (l’icône « lunettes » qui apparaît lorsque vous pointez sur l’exécution du pipeline en cours d’exécution) pour afficher les détails de l’exécution.

![image](https://github.com/user-attachments/assets/4bbc5a1b-4ac2-4412-82f2-6d87b913c51c)


3- Les détails de l’exécution montrent 1 508 501 lignes lues et écrites.

![image](https://github.com/user-attachments/assets/0d5c1745-1fdf-44a5-8ce3-c73925a026ee)


4- Développez la section Répartition des durées pour afficher la durée de chaque étape de l’activité Copy. Après avoir examiné les détails de la copie, sélectionnez Fermer.

![image](https://github.com/user-attachments/assets/3d561e3e-1095-46a2-8b34-2b2a9ac98ee9)
