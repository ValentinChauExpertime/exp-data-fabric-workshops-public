# Créer des requêtes avec le générateur de requêtes visuelles

Dans cette partie nous allons construire des requêtes sur nos tables sans écrire de code. 

Utiliser le générateur de requêtes visuelles
--------------------------------------------

1- Dans l'onglet **Accueil** du ruban, sélectionnez **Nouvelle requête visuelle**.
    
![Capture d’écran du ruban et de l’endroit où sélectionner Nouvelle requête visuelle.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-visual-query/new-visual-query.png#lightbox)
    
2- Faites glisser la table `fact_sale` de l’**explorateur** vers le volet création de requêtes.
    
![image](https://github.com/user-attachments/assets/f43a56f7-24b7-443d-acda-58c3bfe0f1f4)
    
3- Limitez la taille du jeu de données en sélectionnant **Réduire les lignes**, puis **Conserver les lignes supérieures** dans le ruban Transformations.
    
![image](https://github.com/user-attachments/assets/d0169d3c-f672-4eb0-a557-c262f0b49793)
    
4- Dans la boîte de dialogue **Conserver les lignes supérieures**, entrez `10000`.
    
5- Cliquez sur **OK**.
    
6- Faites glisser la table `dimension_city` de l’explorateur vers le volet création de requêtes.
    
7- Dans le ruban de transformations, sélectionnez la liste déroulante en regard de **Combiner**, puis sélectionnez **Fusionner les requêtes comme nouvelles**.
    
![image](https://github.com/user-attachments/assets/04d5d52c-1d40-4a22-b22d-6250915ce5f7)
    
8- Dans la page des paramètres de **Fusion** :
    
  a- Dans la liste déroulante **Table à fusionner à gauche**, choisissez `dimension_city`
        
  b- Dans la liste déroulante **Table à fusionner à droite**, choisissez `fact_sale`
      
  c- Sélectionnez le champ `CityKey` dans la table `dimension_city` en sélectionnant le nom de colonne dans la ligne d’en-tête pour indiquer la colonne de jointure.
        
  d- Sélectionnez le champ `CityKey` dans la table `fact_sale` en sélectionnant le nom de colonne dans la ligne d’en-tête pour indiquer la colonne de jointure.
        
  e- Dans la sélection du diagramme **Type de jointure**, choisissez **Interne**.
        
    
![image](https://github.com/user-attachments/assets/02e1a2e6-38ff-461f-abfc-7650e9457055)
    
9- Cliquez sur **OK**.
    
10- Une fois l’étape **Fusionner** sélectionnée, sélectionnez le bouton **Développer** en regard de `fact_sale` dans l’en-tête de la grille de données, puis sélectionnez les colonnes `TaxAmount`, `Profit`et `TotalIncludingTax`.
    
![image](https://github.com/user-attachments/assets/2b90ddff-f0ce-440b-b714-9a779a57f953)
    
11- Cliquez sur **OK**.
    
12- Sélectionnez **Transformer**, puis **Regrouper par** dans le ruban Transformations.
    
![Capture d’écran du ruban Transformations et de l’endroit où sélectionner Regrouper par dans le menu déroulant Transformer.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-visual-query/transform-group-by.png#lightbox)
    
13- Dans la page des paramètres de **Regrouper par** :  
    
  a- Changez pour **Avancé**.  
        
  b- **Regrouper par** (si nécessaire, sélectionnez **Ajouter un regroupement** pour ajouter d’autres groupes par colonnes) :  
        
        1- `Country`  
        2- `StateProvince`  
        3- `City`  
  c- **Nouveau nom de colonne** (si nécessaire, sélectionnez **Ajouter une agrégation** pour ajouter d’autres opérations et colonnes d’agrégation) :  
        
- `SumOfTaxAmount`  
- Choisissez **Opération** de **Somme** et **Colonne** de `TaxAmount`.  
- `SumOfProfit`
- Choisissez **Opération** de **Somme** et **Colonne** de `Profit`.
- `SumOfTotalIncludingTax`
- Choisissez **Opération** de **Somme** et **Colonne** de `TotalIncludingTax`.
    
![image](https://github.com/user-attachments/assets/fd8be0db-1656-4366-ae9d-f54f6df55474)
    
14- Cliquez sur **OK**.
    
15- Cliquez avec le bouton droit sur **Requête visuelle 1** dans **Explorateur**, puis sélectionnez **Rename**.
    
![Capture d’écran de l’endroit où sélectionner avec le bouton droit la nouvelle requête visuelle dans le volet Explorateur et de l’endroit où sélectionner Renommer.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-visual-query/rename-visual-query.png#lightbox)
    
16- Tapez `Sales Summary` pour changer le nom de la requête.
    
17- Appuyez sur **Entrée** sur le clavier ou sélectionnez n'importe où en dehors de l'onglet pour enregistrer la modification.
