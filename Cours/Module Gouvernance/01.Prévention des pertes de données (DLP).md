# Configurer des stratégies de prévention des pertes de données (DLP) pour Microsoft Fabric

Les stratégies de prévention des pertes de données (DLP) dans Microsoft Fabric aident les organisations à protéger leurs données sensibles en détectant le téléchargement de données sensibles dans des types d’éléments pris en charge. Lorsqu’une violation de stratégie se produit, les propriétaires de données en sont informés, des alertes peuvent être envoyées aux propriétaires et aux administrateurs de la sécurité, et les violations peuvent être analysées.

Ce lab décrit comment configurer des stratégies DLP dans Microsoft Purview pour Fabric. Il s’adresse principalement aux administrateurs de conformité responsables de la prévention des pertes de données dans leur organisation.

## Prérequis
Le compte utilisé pour créer les stratégies DLP doit faire partie de l’un des groupes de rôles suivants :
  - Administrateur de conformité (Compliance Administrator)
  - Administrateur des données de conformité (Compliance data administrator)
  - Protection des informations (Information Protection)
  - Administrateur Protection des informations (Information Protection Admin)
  - Administrateur de sécurité (Security administrator)
## Licences requises
Avant de commencer avec DLP pour Fabric et Power BI, vous devez vérifier que votre abonnement Microsoft 365 comprend l’une des licences suivantes :

- Microsoft 365 E5
- Microsoft 365 E5 Compliance
- Microsoft 365 E5 Information Protection & Governance

#Configuration d'une stratégie DLP pour Fabric
Accédez au portail Microsoft Purview, à la page des stratégies DLP, puis sélectionnez + Créer une stratégie.


📌 Remarque : L’option « + Créer une stratégie » n’apparaît que si tous les prérequis sont remplis.
