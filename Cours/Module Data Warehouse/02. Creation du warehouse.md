
Créez votre premier Warehouse
----------------------------

1.  Sélectionnez **Espaces de travail** dans le menu de navigation.
    
2.  Recherchez l'espace de travail que vous avez créé dans Tutoriel : créer un espace de travail Microsoft Fabric en tapant dans la zone de texte de recherche en haut et en sélectionnant votre espace de travail pour l'ouvrir.

    ![image](https://github.com/user-attachments/assets/6385f0bd-ae47-438a-ade7-037cc6b983d3)

    
3.  Sélectionnez le bouton **\+ New** pour afficher une liste complète des éléments disponibles. Dans la liste des objets à créer, choisissez \*\*Warehouse\*\* (entrepôt) pour créer un nouvel entrepôt dans Microsoft Fabric.
    
![image](https://github.com/user-attachments/assets/8c189c19-872a-400b-87b1-561c13b28548)
    
4.  Dans la boîte de dialogue **New warehouse**, entrez `WideWorldImporters` comme nom.
    

1.  Sélectionnez **Create**.
    
![image](https://github.com/user-attachments/assets/c60ed5be-76d3-4e92-a7db-646079a366ac)
    
2.  Lorsque le provisionnement est terminé, la page d'accueil **Build a warehouse** s'affiche.
    
![image](https://github.com/user-attachments/assets/5c9f7047-b2d9-408e-aabe-cedda64a6c66)
