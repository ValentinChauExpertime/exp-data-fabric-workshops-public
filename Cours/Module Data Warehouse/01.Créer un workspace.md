# Créer un espace de travail
Dans cette étape, nous allons créer un espace de travail Fabric. 
L'espace de travail contient tous les éléments nécessaires pour ce projet notamment Lakehouse, Dataflow, les pipelines Data Factory, les notebooks, les modèles sémantiques(dataset) Power BI et les rapports.

1. Connectez-vous à Fabric (http://app.fabric.microsoft.com/)

2. Sélectionnez **Espaces de travail** et **Nouvel espace de travail**.

  ![image](https://github.com/user-attachments/assets/02a0f7f9-f747-43e6-b9cc-35921008c3a2)


3.Remplissez le formulaire Créer un espace de travail avec les détails suivants :

  - **Nom** : entrez _Fabric Lakehouse Tutorial_ et tout caractère supplémentaire pour rendre le nom unique.

  - **Description**: Entrez une description facultative pour votre espace de travail.
    
      ![image](https://github.com/user-attachments/assets/2f8791ca-7542-45fb-ba39-73ba93593738)


  - **Avancé**: sous mode Licence, sélectionnez Capacité d’évaluation gratuite. 
      Vous pouvez également choisir une capacité Fabric avec une référence SKU F64 ou une capacité Power BI Premium avec une référence SKU P1 si vous y avez accès. Ces références SKU vous donnent accès à toutes les capacités Fabric.

      ![image](https://github.com/user-attachments/assets/6624a1f8-49d4-4e38-8155-2fc88ee39841)


4. Sélectionnez **Appliquer** pour créer et ouvrir l'espace de travail.
