
Ingérer des données
-------------------

1.  Dans la page d’arrivée **Build a warehouse**, sélectionnez l’espace de travail **Data Warehouse Tutoriel** (Tutoriel Entrepôt de données) dans le menu de navigation pour revenir à la liste des éléments de l’espace de travail.
    
![image](https://github.com/user-attachments/assets/481d37d1-7df2-4e4f-aede-238ef631a50a)
    
2.  Sélectionnez **New item** pour afficher la liste complète des éléments disponibles.
    
3.  Dans la section **Data Factory**, sélectionnez **Data pipeline**.
    
4.  Dans la boîte de dialogue **New pipeline**, entrez le nom `Load Customer Data`.
    
![image](https://github.com/user-attachments/assets/c92750c0-b2d3-41ac-afbc-7cae4e7b3f8c)
    
5.  Sélectionnez **Create**.
    
6.  Sélectionnez **Pipeline activity**.
    
![image](https://github.com/user-attachments/assets/f1d38944-599d-4134-b701-ed17bd9e5711)
    
7.  Sélectionnez **Copy data** dans la section **Move & transform**.
    
![image](https://github.com/user-attachments/assets/3da46d1a-643b-4d62-8d98-382b990cbdfc)

    
8.  Si nécessaire, sélectionnez l’activité **Copy data**  nouvellement créée dans la zone de conception et suivez les étapes suivantes pour la configurer.
    
9.  Dans la page **General** , pour **Name**, entrez `CD Load dimension_customer`.
    
![image](https://github.com/user-attachments/assets/0ca5d82e-0d27-4096-89b4-4a7ab5fe3944)
    
10.  Dans la page **Source**, sélectionnez la liste déroulante **Connexion**. Sélectionnez **More** pour afficher toutes les sources de données parmi lesquelles vous pouvez choisir, y compris les sources de données dans votre hub de données OneLake local.
    
11.  Sélectionnez **New** pour créer une nouvelle connexion.
    
12.  Dans la page **New connection** , saisissez ou sélectionnez **Azure Blobs** dans la liste des options de connexion.
    
13.  Sélectionnez **Next**.
    
14.  Dans la page **Connection settings**, configurez les paramètres comme suit :

a- Dans **Account name or URL** , entrez `https://fabrictutorialdata.blob.core.windows.net/sampledata/`.
        
b- Dans la section **Connection credentials** , sélectionnez **Create new connection**  dans la liste déroulante de **Connection** .
        
c- Le champ **Nom de connexion** est automatiquement renseigné, mais pour plus de clarté, saisissez-le dans `Wide World Importers Public Sample`.
        
d- Définissez **Authentication kind**  sur **Anonymous**.
        
![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/04_Data_Warehouse/Data_warehouse2.png)

    
15.  Sélectionnez **Connecter**.
    
16.  Modifiez les paramètres restants dans la page **Source** de l’activité de copie comme suit, pour accéder aux fichiers .parquet dans `https://fabrictutorialdata.blob.core.windows.net/sampledata/WideWorldImportersDW/tables/dimension_customer.parquet` :


 Dans les zones de texte **File path** (Chemin du fichier), indiquez :
        
   **Conteneur** : `sampledata`
            
  **File path - Directory :** `WideWorldImportersDW/tables`
            
  **File path - File name :** `dimension_customer.parquet`
            
Dans la liste déroulante **File Format**, choisissez **Parquet**.
        
17.  Sélectionnez **Preview data** en regard du paramètre **File path**  pour vérifier qu’il n’y a pas d’erreurs.
    

![image](https://github.com/Expertime/exp-data-fabric-workshops/raw/main/Images/Fabric/Correction/04_Data_Warehouse/Data_warehouse3.png)
    
18.  Sélectionnez la page **Destination** de l’activité Copier des données. Pour **Connexion**, sélectionnez l’élément d’entrepôt **WideWorldImporters** dans la liste, ou sélectionnez **More** pour rechercher l’entrepôt.
    
19.  En regard du paramètre de configuration **Option de table**, sélectionnez la case d’option **Créer automatiquement une table**.
    
20.  Le menu déroulant situé en regard du paramètre de configuration **Table** se transforme automatiquement en deux zones de texte.
    
21.  Dans la première zone en regard du paramètre **Table**, entrez `dbo`.
    
22.  Dans la deuxième zone en regard du paramètre **Table**, entrez `dimension_customer`.

![image](https://github.com/user-attachments/assets/362d0bc4-3e89-4c11-8be2-56749a34f03e)

    
23.  Dans le ruban, sélectionnez **Run** (Exécuter).
    
24.  Sélectionnez **Save and run** (Enregistrer et exécuter) dans la boîte de dialogue. Le pipeline permettant de charger la table `dimension_customer` démarre.
    
25.  Surveillez la progression de l’activité de copie dans la page **Output** (Sortie) et attendez qu’elle se termine.
    
![Capture d’écran de la page Output (Sortie), montrant à quoi ressemble une exécution qui aboutit.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-ingest-data/monitor-output-page.png#lightbox)
