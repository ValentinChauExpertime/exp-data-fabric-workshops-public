
Ici nous allons créer un rapport avec les données que vous avez ingérées dans votre warehouse à la dernière étape.

Créer un rapport
----------------

1- Sélectionnez le **OneLake data hub** dans le menu de navigation.
    
![image](https://github.com/user-attachments/assets/a2372fa9-266d-4bb6-bbdd-d859753e5c8f)

  
2- Dans la liste des éléments, sélectionnez `WideWorldImporters` avec le type **Modèle sémantique (par défaut)**.
    
    
3- Dans la section **Visualiser ces données**, sélectionnez **Créer un rapport**\>**Créer automatiquement**. Un rapport est généré à partir de la table `dimension_customer` qui a été chargée dans la section précédente.
    
![image](https://github.com/user-attachments/assets/dacfa26a-c7fc-4d37-8f5f-a49fc7afc377)
    
4- Un rapport similaire à l’image suivante est généré.
    
![Capture d’écran d’une page de résumé rapide qui montre quatre graphiques à barres différents comme exemple de rapport créé automatiquement.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-build-report/quick-summary-report-example.png#lightbox)
    
5- Dans le ruban, sélectionnez **Enregistrer**.
    
6- Entrez `Customer Quick Summary` dans la zone du nom. Dans la boîte de dialogue **Enregistrer votre rapport**, sélectionnez **Enregistrer**.
    
![image](https://github.com/user-attachments/assets/bed6f6e8-7e27-4924-9d03-a3795b5e2da7)
