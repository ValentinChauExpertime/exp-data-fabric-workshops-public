

Charger des données à l'aide de T-SQL
------------------------------------------------


Charger les données avec COPY INTO
----------------------------------

1- Dans le ruban, sélectionnez **Nouvelle requête SQL**.
    
![image](https://github.com/user-attachments/assets/aaa98691-b808-4269-a263-403b7cc2a646)
    
2- Dans l'éditeur de requête, collez le code suivant.
    
```SQL
--Copy data from the public Azure storage account to the dbo.dimension_city table.
COPY INTO [dbo].[dimension_city]
FROM 'https://fabrictutorialdata.blob.core.windows.net/sampledata/WideWorldImportersDW/tables/dimension_city.parquet'
WITH (FILE_TYPE = 'PARQUET');

--Copy data from the public Azure storage account to the dbo.fact_sale table.
COPY INTO [dbo].[fact_sale]
FROM 'https://fabrictutorialdata.blob.core.windows.net/sampledata/WideWorldImportersDW/tables/fact_sale.parquet'
WITH (FILE_TYPE = 'PARQUET');
```

    
3- Sélectionnez **Run** pour exécuter la requête. L'exécution de la requête prend entre 20 et 25min.
    
![image](https://github.com/user-attachments/assets/5b2d3d4b-a5e1-4e8c-9aa8-26d4d9d3bfa0)
    
4- Une fois la requête terminée, passez en revue les messages pour voir les lignes affectées qui indiquaient le nombre de lignes chargées respectivement dans les tables `dimension_city` et `fact_sale`.

![Capture d'écran d'une liste de messages, montrant où trouver le nombre de lignes qui ont été chargées dans les tables.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-load-data/review-query-messages.png#lightbox)
    
6- Chargez l'aperçu des données pour valider les données chargées avec succès en sélectionnant sur la table `fact_sale` dans l'**explorateur**.
    
![image](https://github.com/user-attachments/assets/80be82d3-48a6-4c16-9af7-4a8754b2e4e9)
    
7- Renommez la requête pour référence ultérieure. Faites un clic droit sur la **SQL query 1** dans l'**Explorateur** et sélectionnez **Renmae**.

![image](https://github.com/user-attachments/assets/240348ff-4cb7-4f52-b0c0-c59c1e592031)

    
8- Tapez `Load Tables` pour changer le nom de la requête.
    
9- Appuyez sur **Entrée** sur le clavier ou sélectionnez n'importe où en dehors de l'onglet pour enregistrer la modification.
