
# Introduction


Dans ce tutoriel, vous prenez le rôle d'un Data warehouse engineer et effectuerez les étapes suivantes pour créer et implémenter une solution de data warehouse de bout en bout :

1- Créer un espace de travail Microsoft Fabric.

2- Créer un warehouse.

3- Ingérer des données de la source vers le modèle dimensionnel du warehouse un data pipeline.

4- Créer des tables dans votre warehouse.

5- Charger des données avec T-SQL avec l’éditeur de requête SQL.

6- Cloner une table à l’aide de T-SQL avec l’éditeur de requête SQL.

7- Transformer les données pour créer des jeux de données agrégés à l’aide de T-SQL.

8- Voyager dans le temps en utilisant T-SQL pour voir les données telles qu’elles apparaissent.

9- Utiliser l’éditeur de requête visuel pour interroger l’entrepôt de données.

10- Analyser les données avec un notebook.

11- Créer et exécuter des requêtes entre warehouses avec l’éditeur de requête SQL.

12- Créer des rapports Power BI à l’aide du mode DirectLake pour analyser les données en place.

13- Créez un rapport à partir du hub de données OneLake.

14- Nettoyer les ressources en supprimant l’espace de travail et d’autres éléments.
