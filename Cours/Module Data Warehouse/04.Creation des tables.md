
Créer une table
---------------

1- Sélectionnez **Espaces de travail** dans le menu de navigation.
        
3- Dans la liste des éléments, sélectionnez `WideWorldImporters` avec le type de **Warehouse**.

![image](https://github.com/user-attachments/assets/4189104e-b6cd-417a-9441-969f7baf6bc6)

    
4- Dans le ruban, sélectionnez **New SQL Query**. Sous **Empty**, sélectionnez **New SQL query** pour une nouvelle fenêtre de requête vierge.
    
![image](https://github.com/user-attachments/assets/a7abde6c-934a-4ddc-a508-478acee78e64)

    
5- Dans l'éditeur de requête, collez le code suivant.

```SQL
/*
1. Drop the dimension_city table if it already exists.
2. Create the dimension_city table.
3. Drop the fact_sale table if it already exists.
4. Create the fact_sale table.
*/

-- dimension_city
DROP TABLE IF EXISTS [dbo].[dimension_city];
CREATE TABLE [dbo].[dimension_city]
(
    [CityKey] INT NULL,
    [WWICityID] INT NULL,
    [City] VARCHAR(MAX) NULL,
    [StateProvince] VARCHAR(MAX) NULL,
    [Country] VARCHAR(MAX) NULL,
    [Continent] VARCHAR(MAX) NULL,
    [SalesTerritory] VARCHAR(MAX) NULL,
    [Region] VARCHAR(MAX) NULL,
    [Subregion] VARCHAR(MAX) NULL,
    [Location] VARCHAR(MAX) NULL,
    [LatestRecordedPopulation] BIGINT NULL,
    [ValidFrom] DATETIME2(6) NULL,
    [ValidTo] DATETIME2(6) NULL,
    [LineageKey] INT NULL
);

-- fact_sale
DROP TABLE IF EXISTS [dbo].[fact_sale];
CREATE TABLE [dbo].[fact_sale]
(
    [SaleKey] BIGINT NULL,
    [CityKey] INT NULL,
    [CustomerKey] INT NULL,
    [BillToCustomerKey] INT NULL,
    [StockItemKey] INT NULL,
    [InvoiceDateKey] DATETIME2(6) NULL,
    [DeliveryDateKey] DATETIME2(6) NULL,
    [SalespersonKey] INT NULL,
    [WWIInvoiceID] INT NULL,
    [Description] VARCHAR(MAX) NULL,
    [Package] VARCHAR(MAX) NULL,
    [Quantity] INT NULL,
    [UnitPrice] DECIMAL NULL,
    [TaxRate] DECIMAL NULL,
    [TotalExcludingTax] DECIMAL NULL,
    [TaxAmount] DECIMAL NULL,
    [Profit] DECIMAL NULL,
    [TotalIncludingTax] DECIMAL NULL,
    [TotalDryItems] INT NULL,
    [TotalChillerItems] INT NULL,
    [LineageKey] INT NULL,
    [Month] INT NULL,
    [Year] INT NULL,
    [Quarter] INT NULL
);

```



    
6- Sélectionnez **Run** pour exécuter la requête.

![image](https://github.com/user-attachments/assets/adec1f84-cb50-4dbe-b37e-9ee0fbd92047)
    


Pour enregistrer cette requête pour référence ultérieure, cliquez avec le bouton droit sur l’onglet de requête et sélectionnez **Rename**

![image](https://github.com/user-attachments/assets/93065b6c-fc25-416b-a3fe-6e6fd1754c74)

    
8- Tapez `Create Tables` pour changer le nom de la requête.
    
9- Appuyez sur **Entrée** sur le clavier ou sélectionnez n'importe où en dehors de l'onglet pour enregistrer la modification.
    
10- Validez que la table a été créée avec succès en sélectionnant le bouton d’icône Actualiser sur le ruban.
    
![image](https://github.com/user-attachments/assets/2884b864-b388-40c5-a47d-4ec1cbcc3855)
    
11- Dans l'**explorateur d'objets**, vérifiez que vous pouvez voir la **requête**, la table `fact_sale` et la table `dimension_city`Créer des tables nouvellement créées.
    
![image](https://github.com/user-attachments/assets/6ca11915-e77b-4c3a-96ff-ba648f044159)
