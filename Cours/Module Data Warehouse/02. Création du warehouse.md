
Créez votre premier Warehouse
----------------------------

1.  Sélectionnez **Espaces de travail** dans le menu de navigation.
    
2.  Recherchez l'espace de travail que vous avez créé dans Tutoriel : créer un espace de travail Microsoft Fabric en tapant dans la zone de texte de recherche en haut et en sélectionnant votre espace de travail pour l'ouvrir.
    
    
3.  Sélectionnez le bouton **\+ Nouveau** pour afficher une liste complète des éléments disponibles. Dans la liste des objets à créer, choisissez \*\*Warehouse\*\* (entrepôt) pour créer un nouvel entrepôt dans Microsoft Fabric.
    
    !Capture d'écran de l'écran de l'espace de travail, montrant où sélectionner entrepôt dans le menu déroulant Nouveau.
    
4.  Dans la boîte de dialogue **Nouvel entrepôt**, entrez `WideWorldImporters` comme nom.
    

1.  Sélectionnez **Créer**.
    
    !Capture d'écran de la boîte de dialogue Nouvel entrepôt, montrant où saisir un nom d'entrepôt, définir la sensibilité et sélectionner Créer.
    
2.  Lorsque le provisionnement est terminé, la page d'accueil **Créer un entrepôt** s'affiche.
    
    ![Capture d'écran de la page de destination Créer un entrepôt.](https://learn.microsoft.com/fr-fr/fabric/data-warehouse/media/tutorial-create-warehouse/build-a-warehouse.png#lightbox)
